# Personal Site

Built with Astro, Tailwind CSS, DaisyUI, and GSAP.

## Run it

```bash
npm install
npm run dev
```

Then open http://localhost:4321.

## Make it yours

1. Edit `src/data/content.ts` with your name, projects, and experience.
2. Add your resume as `public/resume.pdf`.
3. Change colors in `src/styles/global.css` (the `monokai` dark theme and the `light` theme).
4. Deploy by pushing to GitHub and importing the repo at vercel.com.
